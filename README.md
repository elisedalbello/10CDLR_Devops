# 10CDLR_Devops

Projeto desenvolvido como **entrega da disciplina de DevOps**, com foco na aplicação prática de **CI/CD**, automação de pipeline e deploy em nuvem.

---

## 🎯 Objetivo do Projeto

Demonstrar, de forma prática, conceitos fundamentais de **DevOps**, incluindo:

- Integração Contínua (CI)
- Entrega Contínua (CD)
- Automação de testes
- Deploy automatizado em ambiente cloud
- Aplicação com **front-end funcional**

---

## 🧩 Arquitetura da Solução

- **Backend:** Java + Maven  
- **Frontend:** Aplicação web simples (HTML/CSS/JS) integrada ao backend  
- **CI/CD:** GitHub Actions  
- **Cloud:** Azure App Service  

---

### Principais etapas:
- **Unit Test** – execução de testes unitários  
- **Build** – empacotamento da aplicação  
- **Deploy** – deploy automatizado no Azure  
- **Smoke Test (Produção)** – validação do front-end e recursos estáticos após o deploy
